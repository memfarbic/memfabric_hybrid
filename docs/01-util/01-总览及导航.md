# util 模块总览及导航

## 模块概述

util 模块提供跨模块的公共工具函数，是整个项目的基础设施层。其他所有模块（acc_links、hybm、smem）都依赖本模块提供的工具。

**目录位置**: `src/util/`

## 模块职责

1. **日志输出**: 提供统一的日志接口和输出工具
2. **同步原语**: 提供自旋锁、读写锁等同步工具
3. **时间工具**: 提供单调时间获取
4. **字符串工具**: 提供字符串处理函数
5. **数值工具**: 提供数值转换和处理函数
6. **网络工具**: 提供 IP 地址验证、网络地址解析
7. **文件工具**: 提供文件操作辅助函数
8. **线程工具**: 提供线程本地存储（TLS）工具
9. **性能打点**: 提供 ptracer 性能打点工具

## 设计理念

### 1. 头文件即实现

util 模块的大部分工具采用头文件实现的方式（模板类、内联函数），方便其他模块直接包含使用。

### 2. 轻量级同步

提供轻量级的自旋锁和读写锁，用于高并发场景下的快速同步。

### 3. 单调时间

提供基于 CPU 指令或系统调用的单调时间获取，避免系统时间调整影响。

### 4. 统一日志

通过 `mf_out_logger.h` 提供统一的日志接口，支持外部日志函数注入。

## 关键数据结构

### 自旋锁 (mf_spinlock.h)

```cpp
class SpinLock {
    std::atomic_flag flag;  // 原子标志位，用于自旋等待
};
```

### 读写锁 (mf_rwlock.h)

```cpp
class RWLock {
    SpinLock spinLock;           // 内部自旋锁
    std::atomic<int32_t> count;  // 读者计数
};
```

enum class LogLevel {

## 阅读顺序建议

### 基础优先

1. 先读 `mf_syntactic_sugar.h` - 了解项目中的语法糖宏
2. 再读 `mf_spinlock.h` 和 `mf_rwlock.h` - 理解同步原语
3. 然后读 `mf_out_logger.h` - 理解日志系统（其他模块大量使用）

### 功能模块

4. 读 `mf_monotonic_time.h` - 时间获取工具
5. 读 `mf_str_util.h` 和 `mf_num_util.h` - 基础数据处理
6. 读 `mf_net.h` 和 `mf_ipv4_validator.h` - 网络相关工具
7. 读 `mf_file_util.h` - 文件操作工具

### 高级功能

8. 读 `mf_tls_util.h` - 线程本地存储
9. 读 ptracer 相关文件 - 性能打点工具

## 前置知识要求

- C++11/14 基础（智能指针、原子操作、lambda 表达式）
- 多线程编程基础（锁、条件变量、线程本地存储）
- Linux 系统编程基础（文件操作、网络编程）
