# hybm 模块总览及导航

## 模块概述

hybm (Hybrid Big Memory) 模块是 MemFabric Hybrid 项目的核心模块，负责全局内存管理、数据操作和传输管理。

**目录位置**: `src/hybm/`

## 模块职责

1. **Global Memory Management (GVA)**: 实现全局虚拟地址（GVA）的全局编排、页表映射策略制定及通过驱动将映射策略注入页表
2. **Data Operation (xcopy)**: 实现 `memcpy with global virtual address`，驱动 xDMA、LD/ST 实现全局内存直接读写
3. **Transport Management**: 链接管理；xcopy 使用 Host RDMA、Device RDMA、UDMA 时，需要建立 QP、Jetty 链接

## 设计理念

### 1. 地址空间布局

```
NPU 设备虚拟地址空间 (0x100000000000 - 0x80000000000, 8TB):
┌────────────────────────────────────────────────┐
│  HyBM HBM 区域                                    │
│  0x100000000000 - 0x18000000000 (8TB)              │
├────────────────────────────────────────────────┤
│  保留区域                                         │
└────────────────────────────────────────────────┘

GVM 区域 (0x280000000000 - 0xA80000000000, 168TB):
┌────────────────────────────────────────────────┐
│  DRAM 池化区域                                    │
└────────────────────────────────────────────────┘
```

### 2. 数据复制方向

| 方向 | 说明 |
|------|------|
| `LH2GH` | 本地 Host 到全局 Host |
| `GH2LH` | 全局 Host 到本地 Host |
| `LD2GD` | 本地 Device 到全局 Device |
| `GD2LD` | 全局 Device 到本地 Device |
| `GH2GD` | 全局 Host 到全局 Device |
| `D2RH` | 本地 Device 到远端 Host |
| `RH2D` | 远端 Host 到本地 Device |

**符号说明**:
- L (Local): 本地
- D (Device): 设备
- G (Global): 全局内存池
- H (Host): 主机

### 3. 关键常量定义

```cpp
constexpr uint64_t HYBM_LARGE_PAGE_SIZE = 2UL * 1024UL * 1024UL;  // 2MB 大页
constexpr uint64_t HYBM_DEVICE_VA_START = 0x100000000000UL;    // NPU 地址空间起始: 16T
constexpr uint64_t HYBM_DEVICE_VA_SIZE = 0x80000000000UL;      // NPU 地址空间范围: 8T
constexpr uint64_t HYBM_ENTITY_NUM_MAX = 511UL;               // entity 最大数量
```

## 关键数据结构

### hybm_options - 配置选项

```cpp
typedef struct {
    hybm_type bmType;           // AI Core 或 Host
    hybm_mem_type memType;       // Device 或 Host 内存
    hybm_data_op_type bmDataOpType; // 数据操作类型
    uint16_t rankCount;          # Rank 数量
    uint16_t rankId;             # 当前 Rank ID
    uint16_t devId;               # 设备 ID
    uint64_t maxHBMSize;         # HBM 最大容量
    uint64_t maxDRAMSize;        # DRAM 最大容量
    hybm_scene scene;            # 使用场景
    bool globalUniqueAddress;    // 是否使用全局统一地址
    hybm_role_type role;         # 角色（sender/receiver/peer）
    uint32_t flags;              # 标志位
    char transUrl[64];           # 传输 URL
    hybm_tls_config tlsOption;    # TLS 配置
} hybm_options;
```
