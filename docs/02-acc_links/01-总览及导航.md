# acc_links 模块总览及导航

## 模块概述

acc_links（Access Control Links）模块是 MemFabric Hybrid 项目的内部通信层，基于 TCP 提供进程间控制命令的通信能力。

**目录位置**: `src/acc_links/`

## 模块职责

1. **TCP 通信基础设施**: 提供基于 TCP 的服务器-客户端通信框架
2. **请求处理**: 管理客户端请求的接收、分发和处理
3. **连接管理**: 管理客户端连接的建立、维护和清理
4. **SSL/TLS 支持**: 提供安全通信能力
5. **共享缓冲区**: 提供高效的数据传输缓冲区

## 设计理念

### 1. 三层架构

```
┌─────────────────────────────────────────┐
│         Application Layer               │
│         (使用 acc_links API)            │
├─────────────────────────────────────────┤
│         Server Layer                    │
│  ┌──────────┐  ┌──────────┐             │
│  │ Listener │  │  Worker  │             │
│  └──────────┘  └──────────┘             │
├─────────────────────────────────────────┤
│         Link Layer                      │
│  ┌──────────┐  ┌──────────┐             │
│  │TcpServer │→ │ TcpLink  │             │
│  └──────────┘  └──────────┘             │
├─────────────────────────────────────────┤
│         Transport Layer                 │
│         (TCP Socket)                    │
└─────────────────────────────────────────┘
```

### 2. Reactor 模式

- **Listener**: 监听新连接，接受连接请求
- **Worker**: 处理 I/O 事件和业务逻辑
- **Link**: 管理单个连接的状态和数据

### 3. 请求-响应模型

```cpp
// 请求处理流程
Client Request → Listener → Worker → Request Handler → Response → Client
```

## 关键数据结构

### TcpServer

服务器基类，管理监听器和工作线程。

### TcpLink

表示一个 TCP 连接，处理连接的读写和状态管理。

### RequestContext

表示一个请求的上下文，包含请求头、数据等信息。

### SharedBuffer

共享缓冲区，用于高效的数据传输。

## 阅读顺序建议

1. 先读 `include/acc_def.h` - 了解公共定义
2. 再读 `include/acc_tcp_link.h` 和 `include/acc_tcp_server.h` - 理解接口设计
3. 然后读 `csrc/acc_tcp_common.h` - 了解 TCP 公共定义
4. 接着读 `csrc/acc_tcp_listener.cpp` - 理解连接监听
5. 再读 `csrc/acc_tcp_worker.cpp` - 理解工作处理
6. 最后读 `csrc/acc_tcp_server_default.cpp` - 理解完整服务器实现

## 前置知识要求

- TCP/IP 网络编程基础
- Linux 系统编程（socket、epoll、pthread）
- C++ 面向对象设计
- Reactor 设计模式
