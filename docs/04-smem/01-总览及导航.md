# SMEM 模块总览及导航

## 1. 模块概述

SMEM (Semantic Memory) 是 MemFabric Hybrid 项目的语义接口层，位于 `src/smem/` 目录下。该模块提供三大核心 API：

- **BM API** - Big Memory 大内存管理接口
- **SHM API** - Share Memory 共享内存接口
- **Trans API** - Transfer 传输接口

## 4. 核心组件说明

### 4.1 Common 组件

提供 smem 模块的通用基础设施，包括：

- **smem_define.h** - 宏定义（LIKELY/UNLIKELY、错误设置宏等）
- **smem_logger.h** - 日志宏定义
- **smem_last_error.h/cpp** - 线程安全的错误信息存储
- **smem_ref.h** - 引用计数智能指针（SmRef、SmReferable）
- **smem_timedwait.h** - 超时等待机制（替代 sem_timedwait）
- **smem_types.h** - 错误码和常量定义

### 4.2 Config Store 组件

提供基于 TCP 的分布式键值存储服务，用于：

- 集群元数据管理
- 服务发现与注册
- 集群通信协调
- 故障检测与恢复

主要类：
- `ConfigStore` - 配置存储接口
- `ConfigStoreManager` - 配置存储管理接口
- `TcpConfigStore` - TCP 实现
- `PrefixConfigStore` - 前缀包装器
- `SmemLocalMemoryBackend` - 本地内存后端

### 4.3 Net 组件

提供组通信能力，支持：

- 集群 Barrier（屏障同步）
- 集群 AllGather（全收集）
- 动态组成员管理
- 链路状态监控

主要类：
- `SmemNetGroupEngine` - 组通信引擎
- `UrlExtraction` - URL 解析工具

### 4.4 BM API 组件

大内存管理 API，提供跨节点的统一内存空间：

- 支持本地 HBM 和 DRAM 内存贡献
- 支持动态成员加入/退出
- 支持多种数据操作类型（SDMA、RDMA、TCP等）

主要类：
- `SmemBmEntryManager` - BM 条目管理器
- `SmemBmEntry` - BM 条目

### 4.5 SHM API 组件

共享内存 API，为设备侧（AI Core）提供对称内存：

- 设备侧对称内存管理
- 集群控制操作（Barrier、AllGather）
- 拓扑可达性查询

主要类：
- `SmemShmEntryManager` - SHM 条目管理器
- `SmemShmEntry` - SHM 条目

### 4.6 Trans API 组件

传输 API，提供点到点的数据传输功能：

- Sender/Receiver 角色
- 动态成员发现
- 内存注册与传输
- 故障恢复

主要类：
- `SmemTransEntryManager` - Trans 条目管理器
- `SmemTransEntry` - Trans 条目
- `SmemStoreHelper` - 存储辅助类

### 4.7 Python Wrapper 组件

提供 Python 语言绑定：

- `pymf_hybrid` - 主模块 Python 绑定（SMEM、SHM、BM）
- `_pymf_transfer` - 传输适配器 Python 绑定

## 6. 使用流程概览

### 6.1 BM API 使用流程

```c
// 1. 配置初始化
smem_bm_config_t config;
smem_bm_config_init(&config);

// 2. 模块初始化
smem_bm_init(store_url, world_size, device_id, &config);

// 3. 创建 BM 对象
smem_bm_t bm = smem_bm_create(id, member_size, data_op_type, local_dram_size,
                               local_hbm_size, flags);

// 4. 加入全局空间（动态场景）
smem_bm_join(bm, flags);

// 5. 数据传输
smem_bm_copy(bm, &params, copy_type, flags);

// 6. 销毁对象
smem_bm_destroy(bm);

// 7. 模块去初始化
smem_bm_uninit(flags);
```

### 6.2 SHM API 使用流程

```c
// 1. 配置初始化
smem_shm_config_t config;
smem_shm_config_init(&config);

// 2. 模块初始化
smem_shm_init(store_ip_port, world_size, rank_id, device_id, &config);

// 3. 创建 SHM 对象
smem_shm_t shm = smem_shm_create(id, rank_size, rank_id, symmetric_size,
                                 data_op_type, flags, &gva);

// 4. 控制操作
smem_shm_control_barrier(shm);
smem_shm_control_allgather(shm, send_buf, send_size, recv_buf, recv_size);

// 5. 销毁对象
smem_shm_destroy(shm, flags);

// 6. 模块去初始化
smem_shm_uninit(flags);
```

### 6.3 Trans API 使用流程

```c
// 1. 配置初始化
smem_trans_config_t config;
smem_trans_config_init(&config);

// 2. 模块初始化
smem_trans_init(&config);

// 3. 创建 Trans 对象
smem_trans_t trans = smem_trans_create(store_url, unique_id, &config);

// 4. 注册本地内存
smem_trans_register_mem(trans, address, capacity, flags);

// 5. 数据传输
smem_trans_write(trans, local_addr, remote_unique_id, remote_addr, size, flags);
smem_trans_read(trans, local_addr, remote_unique_id, remote_addr, size, flags);

// 6. 销毁对象
smem_trans_destroy(trans, flags);

// 7. 模块去初始化
smem_trans_uninit(flags);
```

## 7. 关键设计模式

1. **工厂模式** - `StoreFactory` 创建不同类型的配置存储
2. **包装器模式** - `PrefixConfigStore` 为存储添加前缀
3. **单例模式** - 各 EntryManager 使用单例
4. **RAII** - 使用智能指针管理资源生命周期
5. **观察者模式** - Watch 机制监听远程变化
6. **策略模式** - 不同数据操作类型（SDMA/RDMA/TCP）
